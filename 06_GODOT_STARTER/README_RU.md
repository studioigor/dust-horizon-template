# Godot starter

Это только каркас и структура каталогов, не готовая игра.

Рекомендуемый renderer: Forward+ на desktop, потому что финальный проект рассчитывает на качественный свет, volumetric fog и другие 3D-эффекты.

1. Скопируй экспортированные GLB в `assets/...`.
2. Открой `project.godot` в Godot 4.x.
3. Сначала создай graybox двух локаций.
4. Затем используй `05_GODOT_PROMPT/MASTER_GAME_PROMPT_RU.md` как ТЗ для AI-агента/кодогенератора.
5. Импортируй GLB и собирай hero-зоны вручную.
6. Procedural scatter используй только для повторяемой среды.
7. Перед финальным art pass проверь `07_PRODUCTION/ASSET_SOURCE_MATRIX_RU.md`, чтобы не дублировать дизайн объектов.
