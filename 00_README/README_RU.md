# Пыльный горизонт — production pack

Шаблон для генерации игры в стиле Fallout на движке Godot 4 из [видео на YouTube-канале StudioIgor](https://youtu.be/o2Uno1xtfh8). Включает промпты для генерации ассетов, техническое задание для AI-агента, стартовый проект Godot и производственный чеклист.

Короткая постапокалиптическая first-person мини-игра: выход из убежища → пустошь → заброшенная заправка → поиск деталей → запуск машины под атакой монстров → побег в закат.

## Что уже учтено

Три object sheet'а НУЖНЫ. Они не заменяют Blender environment prompts, а дополняют их:

- Object Sheet 01 — пропы убежища.
- Object Sheet 02 — пропы пустоши и заправки.
- Object Sheet 03 — интерактивные предметы мини-игры.

По этим листам лучше делать отдельные 3D-пропы: терминалы, рычаги, батарею, канистру, генератор, инструменты, дорожные элементы и т. п.

Blender environment prompts нужны для другого уровня ассетов:
- модульная архитектура убежища;
- гермодверь и камера двери;
- terrain/rocks;
- дорога;
- заправка и гараж;
- автомобиль;
- дальнее окружение;
- decals/material support.

Иными словами:
Object sheets = мелкие/средние объекты и интерактивные пропы.
Blender environment prompts = архитектура, hero-assets, крупные environment kits.

## Папки

- `01_PROJECT_BRIEF` — краткий концепт и рамки проекта.
- `02_CONCEPT_ART` — 9 промптов для ключевых кадров.
- `03_OBJECT_SHEETS` — 3 промпта для листов объектов.
- `04_BLENDER_ENV` — 14 промптов для крупных 3D-наборов.
- `05_GODOT_PROMPT` — мастер-промпт для сборки игры.
- `06_GODOT_STARTER` — минимальный каркас проекта Godot + структура ассетов.
- `07_PRODUCTION` — чеклист и порядок производства.

## Короткий пайплайн

1. Сгенерируй 9 concept art изображений.
2. Сгенерируй 3 object sheet изображения и положи их в `03_OBJECT_SHEETS/generated_images`.
3. По object sheet'ам сделай 3D-пропы в Blender.
4. По Blender environment prompts создай архитектуру, дорогу, terrain kit, заправку, машину и дальние ассеты.
5. Экспортируй готовые модели в `.glb` и положи их в `04_BLENDER_ENV/export_glb`.
6. Перенеси `.glb` в соответствующие папки `06_GODOT_STARTER/assets/...`.
7. Открой `06_GODOT_STARTER/project.godot` в Godot 4.x.
8. Используй `05_GODOT_PROMPT/MASTER_GAME_PROMPT_RU.md` как ТЗ для AI-агента/кодогенератора.
9. Сначала собери полный playable graybox, затем заменяй его финальными ассетами.
10. В самом конце — свет, fog, particles, decals, звук, синематики и титры.

## Главный принцип

Не генерировать "целую красивую сцену" как один 3D-объект.
Генерировать отдельные контролируемые наборы, а композицию собирать вручную в Godot.

В радиусе 0–10 м от игрока — ручная расстановка.
10–50 м — ручная + procedural scatter.
50+ м — LOD/MultiMesh/дальний декор.
Горизонт — максимально дешёвая декоративная геометрия.

## Передача проекта

Все пути в документации указаны относительно корня проекта. Пустые каталоги каркаса сохранены с помощью `.gitkeep`.

В Git включаются промпты, документация, сцены и исходные ассеты, в том числе `.blend`, `.glb` и изображения. Кэш Godot, резервные копии Blender, сборки, локальные настройки редакторов и файлы с ключами исключены через `.gitignore`. Настройки экспорта Godot (`export_presets.cfg`) создаются локально: они могут содержать пути и данные подписи.

Для передачи текущей версии без локальных файлов и служебного каталога `.git` выполните из корня проекта:

```sh
git archive --format=zip --output=../dust-horizon-project-pack.zip HEAD
```

Архив содержит только закоммиченные файлы. Перед добавлением новых материалов проверяйте их содержимое и метаданные: `.gitignore` исключает файлы по имени, но не проверяет их на личные данные.
